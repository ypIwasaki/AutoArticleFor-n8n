# AI Keyword Extraction Instructions

The workflow does not call OpenAI or any other AI API automatically.

Instead, each workflow run writes a compact task instruction:

```text
content/ai-extraction-instructions/YYYY-MM-DD.md
```

Version 2 records `instructionVersion: 2`, the target date, `rulesPath`, and
input/output paths. It does not embed the full digest, rule-based candidate
data, search keyword list, or fixed policy.

Read [ai-rules/keyword-extraction.md](ai-rules/keyword-extraction.md) for the
selection criteria and Markdown table contract, then use the read-only input
reader from the project root:

```bash
python3 scripts/read_ai_inputs.py --run-date YYYY-MM-DD --task keyword-extraction --offset 0 --limit 20
```

The structured JSONL `run` record supplies the actual search keywords and time
window. Pass the returned top-level `nextOffset` as `--offset` until `nextOffset`
is `null` to inspect all article titles, excerpts, URLs, and search provenance.
Consult the separately saved rule-based
candidates and, when needed, the Digest or captured bodies. Machine-extracted
candidates are reference material containing noise, not approved additions.
This task does not return body text. To inspect a body, use the article's
`runDate` with `--task article-summary --include-body --article-url 'ARTICLE_URL'`.

The instruction tells the AI to save semantic extraction results as a Markdown
file in the project when file access is available:

```text
content/ai-keyword-candidates/YYYY-MM-DD.md
```

The source digest and rule-based candidate files are saved separately:

```text
content/daily-digests/YYYY-MM-DD.md
content/keyword-candidates/YYYY-MM-DD.md
```

The candidate headings and `Candidate / Category / Confidence / Add / Reason /
Evidence` table remain unchanged so existing analysis can read reviewed results.
`Add: yes` recommends a term; writing this output does not modify search
configuration. Automatic keyword promotion is a separate existing n8n process.

Codex can read the referenced repository files. For an external AI chat, attach
the fixed rules and relevant input data along with the compact instruction;
pasting the instruction alone is insufficient. Older archived instructions and
the existing candidate output format are retained.

`content/keyword-candidates-ai/` is legacy output from an earlier workflow
version and is not generated by the current workflow.
