## Rejected Terms

- Live2D: 業界関連技術ではあるが一般用途の記事も多く、製品名「nizima LIVE」の方が監視精度が高い。
- 新人vtuber / vsinger / karaoke / dance / APEX / minecraft: 一般タグ・属性・ゲーム名で、固有の継続監視対象ではない。
- NEWS / Web / Magazine / Creative / DAY2 / The / Line: 媒体名、日程表記、文脈を失った一般語。
- FlightHub / JustFly / Book / Guide / Phone: VTuberと無関係な検索スパム由来。
- hololive / ぶいすぽっ! などの表記揺れ: 既存キーワードと実質的に重複する。
- ホロアース: 当日の根拠が開発中止後の人員再配置であり、今後の固定監視語として追加しない。
- 個別配信タイトル、単発ハッシュタグ、単発商品名: 既存のタレント名・団体名から追跡できる。
