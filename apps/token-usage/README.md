# 工程別トークン比較

起動: `python3 apps/token-usage/server.py` → http://127.0.0.1:8766/

`content/operation-usage/YYYY-MM-DD.json` (schemaVersion 1) を再読み込み時に取得する読み取り専用アプリです。外部通信・ライブラリのインストールは不要。既存の確認アプリとは独立して動作します。

- 2つの作業日を比較。日別推移から比較日を選択できます。
- 合計、入力、出力、非キャッシュ入力、キャッシュ入力、推論出力を選択。
- 記事対象日、工程名検索、使用量・差分順の並べ替え、表示中の工程のCSV出力。
- 比較日・指標・記事対象日はURLで共有・再表示できます。
- 未計測・記録なしは数値0と区別。部分的に計測された合計には未計測行数を併記。
- 差分は観測値だけの差で、欠測のある日の総消費量・効率・課金額の比較ではありません。
- 生のチャットログ、認証情報、計測ソースのパスは配信しません。

確認: `node apps/token-usage/test-model.mjs` および `python3 -m unittest discover -s apps/token-usage -p 'test_*.py'`

## 削減の比較

画面上部は指標選択に関係なく、非キャッシュ入力・出力・キャッシュ入力・合計の4指標を表示します。増減率と基準値→比較値を並べ、内訳が揃う場合は合計差分の分解も表示します。工程別表示の初期指標は非キャッシュ入力です。

欠測がある場合も観測値の差分として扱い、削減施策の因果効果や費用削減とは断定しません。内訳の欠落で集計対象が揃わない場合は分解を表示しません。未割当・未計測行数・工程の試行回数を併記し、試行回数を記事数とは扱いません。
